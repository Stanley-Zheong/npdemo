# 在线课程学习与考试系统产品需求文档

## 1. 文档定位

本文档是在线课程学习与考试系统 V1 的产品、设计、开发、测试、部署和运营基线。当前仓库只有 Spring Boot、Vue 和健康检查骨架；下述业务能力均为待交付契约，不代表已经实现。

## 2. 产品目标与范围

系统服务企业内部培训：管理员发布课程和题库，企微员工完成学习与考试，通过后获得可核验的证书，管理员可追踪全过程。

V1 范围：

- 单企业组织、企微 OAuth 登录、用户和部门同步、系统内角色配置。
- 课程、HTML 富媒体材料、学习进度、题库、随机组卷、自动保存、断点续考、判分、证书、统计和审计。
- 学员端和管理端响应式 Web 页面。
- PostgreSQL 持久化；封面、材料资源、导出和证书使用可配置对象存储，开发环境可使用本地目录。
- Docker Compose 本地/验收部署，生产环境支持独立数据库、HTTPS、备份和监控。

V1 不包括公开注册、多租户、付费/直播、主观题、人工阅卷、原生 App、公开证书分享、摄像头监考和屏幕录制。

成功标准：授权课程可完成学习考试；试卷固定 45 题/100 分；中断后答案和剩余时间可恢复且不倒退；重复提交只产生一个结果和一张有效证书；关键操作可审计。

## 3. 用户与权限

| 角色 | 身份与权限 |
| --- | --- |
| 学员 | 企微在职成员；查看获配课程、学习、考试及本人记录和证书 |
| 培训管理员 | 企微成员加系统角色；管理课程、材料、题库、规则、分配、结果、证书模板和导出 |
| 系统管理员 | 受控企微角色或默认禁用的本地应急账号；管理集成、安全配置、管理员和审计 |
| 系统任务 | 保存、判分、证书、同步和过期处理；不可交互登录 |

权限规则：

- 所有权限均由服务端校验；隐藏前端菜单不构成鉴权。
- 学员只能读取获配的已发布课程，只能修改自己的学习进度和进行中答案。
- 培训管理员不能修改已提交试卷的答案和成绩。
- 只有系统管理员可授予管理角色、配置集成和查看完整审计。
- 导出按请求人权限过滤，下载链接 24 小时失效。

## 4. 企业微信对接

1. 浏览器发起企微 OAuth；服务端校验一次性 `state`、授权码和回调地址。
2. 服务端以企业应用凭据换取身份；浏览器不得接触应用密钥或访问令牌。
3. 以 `corp_id + wecom_user_id` 为外部身份唯一键。首次登录建用户，后续更新姓名、头像、部门和在职状态。
4. 课程可按企微部门或成员分配；部门只影响课程授权，不直接授予管理角色。
5. 支持定时全量同步和管理员手动同步。一次全量读取成功后才可停用已离职成员，避免分页失败误停用。
6. 停用用户不能新建会话，已有会话立即失效；历史记录保留。
7. 企微不可用时已登录会话可持续到自身过期，不允许绕过企微新建会话。本地应急管理员默认禁用，启用、登录和角色变更均审计。

## 5. 数据模型

业务表使用 UUID、UTC 时间和乐观锁版本。

| 对象 | 关键字段和约束 |
| --- | --- |
| User | 外部身份键、姓名、头像、部门快照、角色、`ACTIVE/DISABLED`、最后同步时间 |
| Course | 唯一编码、名称、简介、封面、`DRAFT/PUBLISHED/ARCHIVED`、学习要求、创建人 |
| CourseAssignment | 课程、用户或部门、分配时间；同一目标不得重复 |
| Material | 课程、标题、净化后 HTML、排序、状态、版本；标题在课程内唯一 |
| LearningProgress | 用户、材料、完成状态、最后访问时间；用户与材料唯一 |
| Question | 课程、题型、题干、选项、正确答案、解析、难度、状态、版本 |
| ExamRule | 课程、时长、通过分、重考和结果策略、版本 |
| ExamAttempt | 用户、课程、序号、规则/试卷快照、答案、分数、状态、开始/截止/提交时间、版本 |
| Certificate | 用户、课程、考试、唯一编号、模板快照、颁发时间、`VALID/REVOKED`、文件对象键 |
| AuditEvent | 操作者、动作、对象、结果、请求关联号、脱敏差异、时间；只追加 |

已产生学习或考试记录的课程、材料、题目和规则只能归档/禁用；未引用草稿可删除。用户停用不删除历史，证书只能作废。

## 6. 业务规则

### 6.1 课程与学习

- 草稿仅管理员可见。发布前必须有已发布材料、足量启用题库和有效考试规则。
- 归档后不能开始新考试，已有考试仍可在截止前完成。
- HTML 经服务端白名单净化；禁止脚本、事件属性、iframe 和非受信外链。
- 打开材料记录访问；点击“完成学习”才完成。默认完成全部已发布材料后才能考试。
- 材料重排在单事务中完成，旧版本更新不得覆盖新顺序。

### 6.2 题库和组卷

- 判断题 10 道×1 分，单选题 15 道×2 分，多选题 20 道×3 分，总分 100。
- 单选恰有一个正确选项，多选至少两个且必须完全匹配才得分，判断答案只能为真/假。
- 开始考试时服务端按课程和题型随机、无重复抽题，并固化题目、选项顺序、答案、分值和规则快照。
- 学员作答响应不含答案或解析；提交后按规则决定是否展示解析。
- 题目或规则后续修改不影响已生成考试。

### 6.3 考试生命周期

状态只允许 `IN_PROGRESS -> SUBMITTED` 或 `IN_PROGRESS -> EXPIRED`，终态不可回退。

1. 开始前校验用户状态、课程授权/状态、学习条件、题库和重考限制。
2. 同一用户和课程最多一场进行中考试。重复开始返回同一考试。
3. `deadline_at = started_at + duration`，服务端时间唯一权威；退出、刷新和换设备不暂停计时。
4. 答案变化后 2 秒内保存，切题/退出时立即尝试。请求携带版本，旧版本不得覆盖新答案。
5. 断网时浏览器标记未同步；联网后按题目合并。服务端已终态时停止写入。
6. 恢复时返回同一试卷、已确认答案和按截止时间计算的剩余秒数。
7. 到期拒绝作答并自动提交已保存答案。任务可重试，判分必须幂等。
8. 手动提交显示未答数量并确认。提交使用幂等键；并发/重复请求返回同一结果。
9. 判断和单选完全匹配得分；多选集合完全匹配得分；客户端分数不参与判分。
10. `score >= passing_score` 通过。

默认考试时长 60 分钟、通过分 80、最多 3 次，通过后不可重考。规则版本只影响之后创建的考试。

### 6.4 证书

- 首次通过后通过事务 outbox 异步生成证书；同一考试最多一张。
- 编号格式 `CERT-{UTC年份}-{12位大写字母数字}`，全局唯一且不可重用。
- 证书含姓名、企业、课程、成绩、颁发时间和编号，使用颁发时模板快照。
- 学员可查看/下载本人证书。作废须管理员填写原因，作废不可恢复，不改变考试结果，并显示水印。

## 7. 用户流程

学员主流程：企微登录 → 课程中心 → 课程详情 → 学习材料并完成 → 考试说明 → 开始/继续考试 → 自动保存 → 提交/到期判分 → 个人中心查看证书。

管理员主流程：创建草稿课程 → 编辑材料、题库和规则 → 发布前检查 → 预览并发布 → 分配用户/部门 → 查看学习、考试和证书 → 导出或作废证书。

异常流程：企微失败不创建半成品用户；题库不足阻止发布/开考；保存失败显示未同步并重试；过期后停止作答并幂等判分；证书失败保留通过结果、后台重试并告警。

## 9. 页面与 UI 要求

学员端使用顶部导航，管理端使用左侧菜单和右侧内容区。桌面管理端支持 1280px 以上，学员端支持 375px 以上。所有页面具备加载、空、错误、无权限和重试状态；表单具备标签、约束和就地错误；颜色不是唯一状态提示，键盘焦点可见。

| 页面 | 主要内容 |
| --- | --- |
| 登录/错误 | 企微登录、错误码、关联号、重试 |
| 课程中心/详情/学习 | 搜索筛选、进度、材料目录、安全 HTML、完成和考试入口 |
| 考试说明/答题/结果 | 规则、开始/继续、题号、已答数、服务端倒计时、保存四态、退出、提交、结果 |
| 个人中心 | 资料、课程、考试和证书下载 |
| 课程/材料/题库/规则 | CRUD、预览、净化、排序、数量检查、版本提示和发布 |
| 数据/证书 | 组合筛选、详情、导出和作废 |
| 用户权限/系统设置/审计 | 同步、分配、角色、企微/存储/模板只写密钥、审计查询 |

考试页只显示“保存中/已保存/未同步/保存失败”，以服务端确认时间为准；最后 5 分钟和 1 分钟提醒；题号区分当前/已答/未答，不暗示对错；提交成功只按服务端终态跳转。

## 10. 数据流与指令流

- 登录：浏览器 → `/auth/wecom` → 企微 → 回调 → 服务端换身份 → 绑定/同步用户 → 服务端会话。
- 开考：开始命令 → 权限和业务校验 → 锁定用户课程 → 随机抽题 → 保存规则/试卷快照 → 返回无答案试卷。
- 保存：答案和版本 → 校验归属/状态/截止 → 条件更新 → 返回确认版本。
- 提交：锁定考试 → 校验终态 → 快照判分 → 保存结果/outbox → 返回结果；证书消费以考试 ID 幂等。
- 同步：定时/手动命令 → 分页读取企微 → 外部身份 upsert → 完整成功后停用对账 → 摘要和审计。

## 11. 接口、存储和安全

- JSON API 位于 `/api`，使用 UTF-8、ISO 8601、分页和稳定错误码；写请求校验权限、大小、版本和幂等键。
- PostgreSQL 是业务事实源，结构使用版本化迁移；JSON 仅保存需要保持历史语义的快照。
- 对象存储只通过受控对象键访问，记录哈希、大小和 MIME；禁止路径穿越。
- 全链路 HTTPS；生产 Cookie 使用 `Secure`、`HttpOnly`、`SameSite=Lax`。会话默认空闲 30 分钟、最长 12 小时。
- 服务端防水平/批量越权、CSRF、XSS、SQL 注入、开放重定向、路径穿越和 CSV 公式注入。
- 密钥、会话、正确答案和完整作答不进入前端构建、接口非必要响应或日志。生产弱密码/模拟登录配置导致启动失败。

## 12. 非功能要求

| 维度 | 目标 |
| --- | --- |
| 可用性 | 月度 99.5%，计划维护除外 |
| 性能 | 普通 API P95≤500ms；保存 P95≤800ms；10,000 行查询首屏≤2s |
| 容量 | 5,000 用户、500 在线、200 并发考试，压测后确定扩容 |
| 一致性 | 提交、判分、次数和证书强一致；统计允许分钟级延迟 |
| 恢复 | 每日备份、保留 30 天；RPO 24h、RTO 4h；上线前恢复演练 |
| 兼容性 | Chrome/Edge/Safari/Firefox 当前及前一主版本、企微内置浏览器 |
| 可观测性 | 关联号、结构化日志、健康/就绪、错误率/延迟/任务积压指标和告警 |

## 13. 环境、上线与运营

开发环境允许显式模拟身份和本地文件；staging 使用企微测试应用和独立存储；production 使用生产企微应用、HTTPS、备份和监控。环境不得共享数据库、对象存储、回调或密钥。

上线门槛：迁移在空库和结构副本通过；`make test` 和 `make build` 通过；staging 完成登录、学习、断网/换设备续考、提交、证书、导出和作废；完成 200 并发考试压测、备份恢复演练、安全检查、告警和值班确认。

培训管理员负责内容、答案复核、分配和证书治理；系统管理员负责企微、权限审批、备份、监控和安全更新。课程发布前由另一管理员复核题库、通过分和模板。每月检查同步、保存、过期、证书和导出异常。
