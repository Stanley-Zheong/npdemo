## 全局元素与动作约束

- `REQ-BADGE` 显示需求 ID；`PERMISSION-BADGE` 显示最小角色，不替代服务端鉴权。
- `STATE-STRIP` 标定加载、空、错误/重试和无权限；列表与表单实现时必须由真实状态驱动。
- `CONFIRM-MODAL` 用于提交、发布、归档、角色变更和证书作废；必须写明后果且取消不改变数据。
- `ASYNC-STATUS` 统一为处理中、成功、失败；导出下载链接 24 小时失效。
- `EXAM-SAVE-STATUS` 仅允许保存中、已保存、未同步、保存失败；确认时间来自服务端。
- 所有字段有显式标签、范围/唯一约束和就地错误；颜色不作为唯一状态提示；键盘焦点可见。
