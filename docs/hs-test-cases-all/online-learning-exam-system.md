# 在线课程学习与考试系统 V1 测试用例

## 约定

证据基线为 `docs/prd.md` 和 `docs/delivery-plan.md`。staging 使用企微测试应用、PostgreSQL 和测试对象存储。每个修改用例从只读模板复制独立用户、课程和考试，资源名带用例 ID；不得依赖前一用例。草稿删除、授权撤销、课程归档；考试、证书和审计按运行 ID 隔离保留。

Lane：`API` 需后续自动化合同；`INT` 需真实/替身集成、可控时钟或任务触发；`UI` 需稳定页面元素；`SEC/PERF/RUNBOOK` 使用专项方案。均不表示当前已自动化。

## 自动化交接
