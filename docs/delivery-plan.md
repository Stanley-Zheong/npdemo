# 在线课程学习与考试系统交付计划

## 阶段 0：设计与工程基线

- 交付信息架构、页面流程、线框、高保真稿、组件规范、接口草案和需求追踪表。
- 准备企微测试应用、回调域名、权限和测试成员。
- 引入 PostgreSQL 驱动、迁移、统一错误、关联号、测试数据库和环境配置校验。

验收：空库迁移、健康/就绪、生产弱配置拒绝均可执行；设计覆盖 PRD 全部页面和状态。

## 阶段 1：身份和学习闭环

- 实现企微登录、会话、同步、停用和服务端权限矩阵。
- 实现课程、材料、分配、学习进度和 HTML 净化。
- 完成管理端课程/材料/分配以及学员课程中心/详情/学习页。

验收：真实企微测试成员完成登录—获配—学习—完成；越权、停用、恶意 HTML 和重复分配有测试。

## 阶段 2：考试闭环

- 实现题库校验/版本、规则版本、随机组卷和快照。
- 实现答题、服务端计时、版本保存、断网提示、续考、提交、判分和重考限制。
- 验证并发开始/保存、重复提交和到期任务。

验收：每卷 45 题/100 分、无重复、无答案泄露；刷新/退出/断网/换设备不增加时间且不丢已确认答案；重复提交一个结果。

## 阶段 3：证书和运营

- 实现 outbox、PDF 证书、唯一编号、重试、个人中心。
- 实现查询、CSV、证书作废、审计、后台任务指标和告警。

验收：通过考试最终一张证书；任务重试不重复；越权下载、公式注入、导出过期和作废符合契约。

## 阶段 4：上线准备

- 完成性能、安全、浏览器、企微内置浏览器测试。
- 演练备份恢复、迁移失败、回滚/前滚；导入首批课程并培训管理员。
- staging 试运行后配置生产域名、HTTPS、告警、备份和值班。

验收：200 并发考试达到指标；RPO/RTO 演练通过；无未接受的高风险安全问题。

## UI 设计交付要求

- 学员/管理员信息架构和导航；PRD 页面清单的逐页高保真稿。
- 每页加载、空、错误、无权限、禁用、成功和危险确认状态。
- 考试保存四态、断网、即将到期、未答提交、过期和重复进入状态。
- 色彩、排版、间距、按钮、表单、表格、筛选、分页、对话框、通知和焦点规范。
- 375/768/1280/1440px 断点，课程和考试移动端稿。
- 两条可点击主链路：管理员发布课程；学员学习、续考、提交并领取证书。
- 标注需求 ID、字段校验、权限、接口数据、埋点和无障碍要求。

设计验收：页面有唯一入口；修改操作有成功、失败、重复和无权限反馈；后台任务可区分处理中/成功/失败；作答态不含答案；核心链路键盘可用并满足 WCAG 2.1 AA 对比度。

## 开发完成定义

- 需求有实现、接口、迁移和最近层自动化测试。
- 正常、参数、权限、并发/幂等和持久化回读均验证。
- 前端有 loading/empty/error/retry，不吞服务端错误码。
- 日志审计脱敏，无凭据、生成物或调试开关。
- `make test` 通过；结构/依赖变更时 `make build` 通过；文档同步。

## 需求级验收标准

| 需求 | 可观察结果 |
| --- | --- |
| IAM-01 | 合法登录建立会话；篡改/过期/重放失败；退出和两类会话过期使旧 Cookie 失效 |
| IAM-02 | 首登创建、复登更新、完整同步停用均可回读且有审计 |
| IAM-03 | 仅系统管理员授予管理角色，变更即时影响 API |
| IAM-04 | 个人中心只显示本人数据，企微权威字段不可改 |
| CRS-01 | 发布一次返回全部缺口；发布后授权可见，归档后不能新开考试 |
| CRS-02 | 材料 CRUD/上下架/排序持久化，危险 HTML 被移除 |
| CRS-03 | 用户/部门分配可回读且重复不产生重复授权 |
| CRS-04 | 未授权、草稿、归档课程在列表和直接访问都不可见 |
| CRS-05 | 完成跨会话保持，材料未全完成时 API 拒绝开考 |
| EXM-01 | 三类题校验准确，已入卷题目编辑不改变快照 |
| EXM-02 | 新规则只影响新考试 |
| EXM-03 | 每卷 10/15/20 题、无重复、100 分且响应无答案 |
| EXM-04 | 导航/已答数正确，保存有服务端版本，旧版本不覆盖新答案 |
| EXM-05 | 刷新、退出、断网、换设备恢复同一试卷/答案/剩余时间 |
| EXM-06 | 手动/到期/并发提交返回同一服务端分数 |
| EXM-07 | 单进行中、次数、通过后和课程状态均由服务端执行 |
| CERT-01 | 通过最终生成一张可打开 PDF，重试不增加证书 |
| CERT-02 | 仅本人/授权管理员下载；作废需原因且不可恢复 |
| OPS-01 | 组合/时间筛选的行、总数和数据库事实一致 |
| OPS-02 | CSV 与筛选一致，公式转义，24 小时后拒绝 |
| OPS-03 | 约定事件含操作者、对象、结果和关联号且无敏感信息 |
| OPS-04 | 依赖异常时就绪失败，指标/日志可定位关键错误 |

## 风险控制

| 风险 | 控制 |
| --- | --- |
| 企微应用未就绪 | 阶段 0 验证真实回调，模拟身份禁止进入 staging/production |
| 题库答案错误 | 发布前双人复核并记录 |
| 并发保存覆盖 | 版本条件更新和冲突回读 |
| 到期/手动提交竞态 | 行锁或条件状态迁移加幂等键 |
| 富文本 XSS | 服务端净化、CSP 和回归测试 |
| 证书任务丢失 | outbox、幂等消费、重试和告警 |
