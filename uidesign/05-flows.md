# 核心可点击流程

## 管理员发布课程

1. `course-management.html`：筛选或新建课程，进入课程编辑。
2. `course-editor.html`：填写编码、名称、简介和封面；保存草稿提供成功/失败/冲突反馈。
3. 从管理端导航进入 `materials.html`、`questions.html`、`rules.html` 补齐内容与规则。
4. 返回编辑页查看一次性发布缺口。多选题不足或未完成双人复核时，发布按钮弹出阻断原因且不改变状态。
5. 条件满足后预览、发布并分配用户/部门；重复分配不重复授权。发布和分配均进入审计。

## 学员学习、续考、提交与证书

1. `login.html`：发起企微 OAuth；失败展示错误码、关联号和重试，不创建用户半状态。
2. `courses.html` → `course-detail.html`：只发现获配已发布课程，查看学习门槛与材料进度。
3. `learning.html`：阅读净化后的材料，主动完成；未完成全部材料时不能开考。
4. `exam-guide.html`：确认规则后开始或返回唯一进行中考试。
5. `exam.html`：题号导航、服务端倒计时和保存四态。断网显示未同步；换设备恢复同一试卷、已确认答案和不增加的剩余时间。
6. 未答提交先显示数量并确认；服务端终态成功后才进入 `exam-result.html`。重复/并发提交返回同一结果。
7. 通过后证书任务可处于处理中/成功/失败；成功后在 `profile.html#certificates` 下载本人证书。
