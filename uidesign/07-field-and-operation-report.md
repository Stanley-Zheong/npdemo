# 字段检查与操作流程开发报告

## 核心实体字段

| 实体 | 必要字段与约束 | 主要页面 | 开发注意 |
| --- | --- | --- | --- |
| User | UUID、企微外部键、姓名、头像、部门、角色、状态、同步时间、版本 | 登录、个人中心、用户权限 | 企微字段只读；停用立即失效；角色仅系统管理员授予 |
| Course | UUID、唯一编码、名称、简介、封面、状态、学习要求、创建人、版本 | 课程管理/编辑、课程中心/详情 | 发布后编码不可改；被引用对象只归档 |
| CourseAssignment | 课程、用户/部门、分配时间 | 课程管理、用户权限 | 唯一约束保证重复分配幂等 |
| Material | 课程、唯一标题、净化 HTML、排序、状态、版本 | 材料管理、学习材料 | 服务端白名单净化；排序事务与乐观锁 |
| LearningProgress | 用户、材料、完成、最后访问 | 详情、学习、个人中心 | 打开不等于完成；用户材料唯一 |
| Question | 类型、题干、选项、答案、解析、难度、状态、版本 | 题库管理 | 客户端作答载荷不含答案/解析；入卷后快照不变 |
| ExamRule | 时长、通过分、次数、重考/结果策略、版本 | 考试规则/说明 | 新版本只影响新考试 |
| ExamAttempt | 用户、课程、序号、快照、答案、分数、状态、截止、版本 | 考试说明/答题/结果 | 单进行中；服务端计时；保存版本；提交幂等 |
| Certificate | 用户、课程、考试、唯一编号、模板快照、时间、状态、对象键、作废原因 | 个人中心、证书管理 | 同考试最多一张；作废不可恢复，不改成绩 |
| AuditEvent | 操作者、动作、对象、结果、关联号、脱敏差异、时间 | 审计日志 | 只追加；不得记录密钥、会话、答案或完整作答 |

## 动作与接口边界

| 动作 | UI 反馈 | 建议 API 数据 | 权限/一致性 |
| --- | --- | --- | --- |
| 登录/回调 | 错误码、关联号、重试 | OAuth state、授权码；浏览器不接触密钥 | 防重放/CSRF/开放重定向 |
| 保存课程/材料/规则 | 保存中、成功、字段错误、版本冲突 | DTO + `version` | 管理员；条件更新和回读 |
| 发布课程 | 一次展示全部缺口 | courseId、version、幂等键 | 培训管理员 + 双人复核；原子状态迁移 |
| 分配课程 | 成功/重复等价成功/无权限 | courseId、targetType、targetIds | 服务端行级权限；唯一约束 |
| 完成学习 | 保存/失败/重试 | materialId、version | 仅本人且课程获配 |
| 开始/恢复考试 | 开始或继续同一场 | courseId | 锁定用户课程；固化题目/规则快照 |
| 保存答案 | 保存中/已保存/未同步/失败 | attemptId、questionId、answer、version | 截止/终态校验；旧版本不覆盖 |
| 提交考试 | 未答确认、处理中、唯一结果 | attemptId、幂等键 | 服务端判分；并发返回同终态 |
| 证书生成/下载/作废 | 任务三态、过期/无权限、危险确认 | examId；certificateId；reason | outbox 幂等；本人/授权管理员；原因必填 |
| 查询/导出 | 加载、空、错误、任务三态 | 组合筛选、分页、字段选择 | 权限过滤；CSV 防公式注入；链接 24h |

## 开发验收顺序

1. 先固化服务端角色、行级授权、错误码、幂等和乐观锁契约。
2. 实现身份和课程/材料垂直切片，使学员能完成获配课程学习。
3. 实现不可变试卷快照、服务端截止时间、答案版本保存和唯一提交终态。
4. 接入证书 outbox、查询导出和只追加审计。
5. 前端逐页接入 loading/empty/error/retry，不吞服务端错误码；以服务端回读驱动保存和任务状态。
6. 按测试基线验证权限、冲突、断网/换设备、到期/并发提交、证书重试与导出过期，再做浏览器、性能、恢复和安全门。
