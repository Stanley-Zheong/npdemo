# 设计系统

## 原则

- 清晰：页面标题、需求标识、权限标识与主操作形成稳定层级。
- 一致：19 页共享 `html/assets/tokens.css` 和 `html/assets/app.js`，不复制业务壳层。
- 有度：4px 基础网格，常用间距 8/12/16/20/28px，卡片圆角 12px。
- 开放：内容区支持卡片、表格、表单和考试工作区；语义 token 可在不改结构的情况下换肤。

## 视觉与可访问性

- 品牌 `#176b5d`，深色 `#104a41`，正文 `#182522`，错误 `#c43d4b`。按钮和文本对比按 WCAG 2.1 AA 目标选择。
- 正文使用系统中文字体栈，基础字号 14px；状态不只依赖颜色，同时显示文字和边框。
- 所有可操作控件具备 `:focus-visible`；原型使用语义化按钮、链接、输入与表格。
- 断点覆盖 375/768/1280/1440px：小于 768px 单列；小于 1280px 指标两列；管理端主场景 1280px 以上。

## 组件

共享模式包括管理端 shell、学员顶部导航、页面标题/追踪标识、筛选工具栏、表格、表单字段、状态条、通知、确认弹窗和考试题号导航。危险动作必须说明后果；保存与异步任务必须显示真实状态。
