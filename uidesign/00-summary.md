# 知行学堂 UI 设计摘要

本设计以 `docs/prd.md` 和 `docs/delivery-plan.md` 为产品与验收事实源，覆盖企业内部在线学习、考试、证书及运营管理。交付包含 19 个业务页面、统一响应式 HTML 原型、静态 JPG、页面知识基线、字段/动作报告及两轮走查。

## 核心场景

- 学员通过企微登录，发现获配课程，完成安全 HTML 材料，开始或恢复考试，按服务端状态提交，并查看证书。
- 培训管理员配置课程、材料、题库和规则，完成发布检查与双人复核，分配课程，查询数据并治理证书。
- 系统管理员维护集成、管理员角色和完整审计；系统任务处理同步、过期、判分、导出和证书。

## 设计决策

- 学员端采用顶部导航并优先适配 375px；管理端采用左侧导航与高密度内容区，桌面端以 1280px 以上为主。
- 绿色品牌色表达可信与成长；状态同时使用文字/形状，键盘焦点始终可见。
- 每页显示需求 ID、角色边界和加载/空/错误/无权限状态。HTML 是响应式与交互事实源，JPG 是 1440px 静态审阅稿。
- 危险动作二次确认；异步任务明确处理中/成功/失败；考试仅显示保存中、已保存、未同步、保存失败，不暗示答案对错。

## 优先级

- P0（由核心闭环推断）：身份、课程/材料、考试、证书、权限与审计。
- P1（由运营闭环推断）：组合筛选、导出、统计、同步、系统配置与响应式可访问性。
- P2：PRD 明确排除的公开注册、多租户、付费、直播、主观题、原生 App 和公开证书分享不设计。

## 假设与开放项

- PRD 未提供品牌规范，采用 WCAG AA 可读的墨绿系统；开发前可在不改变语义 token 的前提下换肤。
- 系统通知渠道未明确，原型仅提供站内反馈和任务状态，不推断短信、邮件或企微消息推送。
- 原型使用真实感示例数据，不代表生产数据或已实现 API；最终字段和接口以 PRD 及后续 API 契约为准。
